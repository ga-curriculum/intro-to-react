## What is React?

- An open-source JavaScript library created by Facebook engineer Jordan Walke for building User Interfaces.
- Initially used to implement Facebook’s newsfeed in 2011 and in Instagram in 2012.
- It was open-sourced in May of 2013 and is now being used by companies such as Netflix, Imgur, Airbnb, Walmart, and many more..

## Core Concept

React is the leading JavaScript library, primarily used for developing single-page applications (SPAs).  React apps consist of **components** that we code using JavaScript.

Its strength lies in its component based architecture, allowing developers to encapsulate elements of the user interface into reusable building blocks.  This approach facilitates a more modular development process and provides more dynamic user interfaces.

## Usage and Popularity

React is one of the most popular advanced front-end libraries in use today.  It has been widely adopted by many prominent tech companies and boasts an active open-sourced community.  This widespread support makes it a dependable choice for tech companies, which in turn, increases the number of available React roles and further expands the open-source community.
